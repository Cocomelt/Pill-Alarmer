About background alarms

Opened as a local file or a plain browser tab, the alarm fires reliably while this app is open or running in the background (not force-closed). For alarms to also work when the phone browser is fully closed, this page needs to be hosted online over HTTPS and installed as a home-screen app — ask me if you'd like help setting that up for free (e.g. with GitHub Pages).
